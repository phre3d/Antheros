# Tags Meta

- Tags are always singular (unless the plural is intrinsic to the name)
- Omit 'the' at the start of a tag
- No more that 3 levels of nesting
- Caps vs. Lower case
	- Top level tags are capitalized
	- Plot/module names are capitalized
	- all other tags are lower case
- The lowest level tag may be the name of a specific instance, generally only used when some other thing may need to be tagged to a specific instance.  e.g. guilds names are used to that people can be tagged to that guild


In the following sections, words surrounded by % are placeholders for the actual tag value.
